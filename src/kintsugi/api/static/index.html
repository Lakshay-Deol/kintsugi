Frequently Asked Questions

Answers Grounded in Reality

How does Kintsugi prevent hallucinated repair steps?
Kintsugi uses a three-tier gate architecture. First, a deterministic hazard gate screens high-risk queries. Second, an Atlas hybrid retrieval gate refuses out-of-domain queries if search relevance scores fall below calibrated thresholds. Third, a programmatic citation verifier cross-references all cited page numbers against retrieved chunks, automatically stripping ungrounded pages.
Can Kintsugi run offline without an internet connection?
Yes. Kintsugi features local CPU ONNX vectorization via FastEmbed and an in-memory cosine fallback. For LLM generation, it supports model-swapping to local open-weights Gemma models (such as gemma3:12b) running on Ollama, making it completely functional for air-gapped workshops.
Where is my diagnostic query data stored?
Your search queries and job history are stored solely in your browser's localStorage. No customer diagnostic symptom text is stored on our servers. In cloud mode, queries are processed via Google AI Studio subject to their API terms of service.
